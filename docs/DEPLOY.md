# 🚀 Production Hybrid Deployment Guide

This guide describes how to deploy the **Inference Gateway** on **Render** (Free Tier) while securely tunneling heavy model execution to your local **Apple Silicon or GPU-enabled hardware** via **ngrok**.

This hybrid deployment strategy gives you a live public production URL, fully functioning asynchronous Celery workers, and a secure Redis instance, all with **$0.00 hosting costs**.

## 🛠️ Deployment Steps

### Step 1: Open the ngrok tunnel on your Mac
Expose your local Ollama instance securely to the public internet:
1. Run Ollama locally (`ollama serve`).
2. Start the tunnel on port `11434` (now installed via Homebrew):
   ```bash
   ngrok http 11434
   ```
3. Copy the public HTTPS forwarding URL generated by ngrok (e.g., `https://a1b2-34-56-78.ngrok-free.app`).
   *⚠️ Keep this terminal tab open to maintain the tunnel!*

---

### Step 2: One-Click Deploy on Render
1. Create a free account on [render.com](https://render.com/).
2. Click **New ➔ Blueprint**.
3. Connect your GitHub repository containing the gateway code.
4. Render will parse `render.yaml` and configure three linked services:
   * 🗄️ `inference-gateway-redis` (Managed Redis Cache)
   * 🐍 `inference-gateway` (FastAPI Gateway)
   * ⚙️ `inference-gateway-worker` (Celery background worker)

5. **Update Environment Variables:**
   * In your Render dashboard, navigate to the `inference-gateway` and `inference-gateway-worker` services.
   * Under the **Environment** tab, set `OLLAMA_BASE_URL` to your copied **ngrok public URL** (e.g. `https://xxxx.ngrok-free.app`).
   * Save changes to trigger an automatic rolling redeployment.

---

## 🧪 Verification & Health Check
* **Check REST API:** Visit the live URL path `/health` (e.g., `https://inference-gateway.onrender.com/health`). It should return `{"status": "healthy"}`.
* **Test Async Queue:** Submit tasks from the Playground UI and verify the Celery worker prints the incoming request task inside the Render console log stream!
